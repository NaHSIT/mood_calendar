# 公共接口与业务约定（A 实现并冻结）

本文件是协作协议，不代表接口已存在。A 先把以下约定实现为可编译 Kotlin 契约并在交付文件公布完整签名；其他窗口以冻结后的代码签名为准。共有契约仅 A 可改。

## 目录及依赖

根包：`com.example.mdd_calender`。

- `domain/model/`、`domain/port/`、`domain/policy/`：A 管理的纯 Kotlin 模型、接口和策略定义。
- `data/care/`、`security/`：A 管理的持久化、加密和访问策略。
- `feature/assessment/`：B；`feature/health/`：C；`feature/risk/`：D。
- `feature/teacher/`、`integration/school/`：E；`feature/followup/`：F。
- `integration/app/`：G，负责依赖装配、事件接线及启动恢复。
- 测试在 `src/test` 或 `src/androidTest` 下使用对应包，文件名不得跨窗口复用。

## 公共实体

所有事件使用稳定 ID，时间点统一 UTC epoch milliseconds；日历日期使用 ISO 日期及明确时区；时钟可注入。计分结果与处置优先级是不同字段。

| 实体 | 必备字段与语义 |
|---|---|
| ActorContext | actorId、role、演示/真实数据域；由可信会话提供，不接受页面随意构造的角色作为授权依据 |
| StudentRef | 内部 studentId、对外 studentCode；真实身份映射独立保存 |
| AssessmentRecord | studentId、量表类型/版本、逐题答案、总分、症状分段、完成时间、计分版本；允许草稿但草稿不能参与预警 |
| HealthConsent | studentId、心率/睡眠授权范围、开关状态、修订号、变更时间 |
| RawHealthSample | ownerId、来源、类型、时间、数值/单位、质量、是否模拟；仅学生本人访问 |
| PhysiologySignal | studentId、粗粒度异常类型、时间窗口、质量、有效期、规则版本、授权修订号、模拟标识；不含原始序列 |
| EvaluationResult | assessmentIds、基础关注等级、处置优先级、辅助标签、数据充分性、规则版本、生成时间 |
| AlertEvent | eventId、studentCode、等级、最少必要原因标签、发生时间、规则版本、评估引用、去重键；内部字段不得直接序列化给教师 |
| TeacherAlertSummary | eventId、studentCode、风险等级、最少必要标签、时间、处置状态；无原始数据、逐题答案、详细分数、日记 |
| DeliveryRecord | alertId、接收对象、尝试次数、下次重试时间、模拟标志、幂等键、投递状态与回执 |
| InterventionCase | caseId、studentId、责任人、alertId、状态、启动时间、最少必要处置记录 |
| AaEnrollment | studentId、关联干预、入库时间、状态、随访策略版本、退出申请与审核记录 |
| FollowUpTask | taskId、studentId、类型、到期时间、完成时间、关联测评、状态；打卡不等于完整量表复测 |
| AuditEvent | actor、动作、对象代号、结果、时间；不复制敏感正文 |

教师工作信息（干预记录、任务到期/完成、AA 状态）可以在职责范围访问；这不意味着可读取原始健康或量表数据。

## 公共接口职责

统一以显式成功/失败结果表达授权拒绝、数据缺失、未接入、暂时失败，不以空列表掩盖越权。

- `SessionProvider`：提供当前可信身份；演示身份与真实存储隔离。
- `AssessmentRepository`：本人保存/查询量表；内部评估通道提供受控输入。
- `ConsentRepository`：读取及更新授权，变更修订号；支持观察变更。
- `StudentHealthRepository`：本人访问及按授权范围删除原始数据；删除必须同时校验可信会话中的本人和数据域，内部信号提取通道独立于教师接口。
- `HealthDataProvider`：能力查询、授权请求/撤回、取消同步、拉取数据；未接入是正常返回状态。
- `PhysiologySignalExtractor`：原始输入转粗粒度信号；C 实现，不承担心理风险判定。
- `RiskEvaluator`：接收有效量表、允许使用的辅助信号和策略，返回可解释评估；D 实现。
- `AlertRepository`：保存事件、查询教师白名单摘要、由责任教师推进处置状态、跟踪投递；同一次评估重复调用幂等。
- `SchoolPlatformGateway`：接收最小化告警 DTO、查询回执、提交处置状态；E 提供未接入及模拟实现。
- `InterventionRepository`：责任人确认及启动干预；保存幂等事件。
- `FollowUpRepository`：入库、任务、退出申请/审核；A 提供事务机制，F 实现业务调度。
- `AuditRepository`：记录最小审计事件，敏感查询及拒绝也可审计。

A 应明确“应用内部评估/事务通道”与“学生/教师查询通道”的区别，不允许教师通过内部通道绕过权限。

## 计分及预警约定

- PHQ-9 为 9 题、GAD-7 为 7 题，每题 0–3；保持两周回顾窗口。具体中文文本及年龄适用性在正式使用前审核。
- PHQ-9 症状分段：0–4、5–9、10–14、15–19、20–27；GAD-7：0–4、5–9、10–14、15–21。
- 演示策略：任一有效量表 10–14 为中度关注；任一 ≥15 为高度关注；5–9 为轻度关注；其余低关注。PHQ-9 的 15–19 和 ≥20 症状分段仍分别保留。该业务映射不是经验证的校园风险预测模型。
- 两份有效量表分别计分，取较高业务关注等级，不相加不取平均。只有一份时标记另一份缺失，已有量表仍可触发预警。
- 完整量表有效期作为配置项，演示默认 14 天；这是业务有效期，不改变量表回顾窗口。
- 无有效量表为 `INSUFFICIENT_DATA`。旧预警不因数据过期或授权撤回自动消失。
- PHQ-9 第 9 题非零增加 `SAFETY_REVIEW_REQUIRED`，进入及时人工安全评估通道；不自动等同紧急危险或诊断。
- 合格生理异常只补充辅助标签和人工复核优先级，不修改总分、不降低量表等级、不单独生成心理高危结论。首版不使用未经校准的权重公式。
- 默认不从日记关键词产生疾病倾向；旧分析器不得继续作为主风险来源。

来源：[PHQ-9](https://www.hiv.uw.edu/page/mental-health-screening/phq-9)、[GAD-7](https://www.hiv.uw.edu/page/mental-health-screening/gad-7)。来源支持量表计分，不支持本项目自定义预警、AA 或生理融合策略。

## 状态机与撤回

- 投递：待发送 → 模拟送达/待重试/失败；教师确认是独立状态。真实适配未接入不能返回真实送达。
- 干预：待确认 → 已确认 → 干预中 → 待结案 → 已结案。
- AA：未入库 → 跟踪中 → 待退出审核 → 已退出；拒绝退出返回跟踪中；新事件允许重新进入。
- 同一学生同时至多一个活动 AA 档案。进入“干预中”与创建/复用 AA 档案采用事务或可靠持久事件，失败可恢复，不依靠页面回调保证一致性。
- 撤回健康授权立即停止相关任务；按当前授权修订号检查在途回调和待发数据，丢弃过期结果。重新评估尚未发送的摘要，去除撤回范围内辅助标签，但保留量表本身需要发送的预警。
- 已送达的最小化历史事件保留必要审计，不声称撤回能收回教师已经看到的内容；授权页须说明这一边界。
- AA 自动退出禁止；稳定条件、响应时限、复测频率为策略配置。演示可用虚拟时钟推进，不将演示数值宣传为临床建议。
- A 的存储边界使用可配置的最短观察期、未完成任务和未处理安全关注作保底校验；功能层可以更严格。批准退出时必须在同一事务中二次检查安全关注并取消未完成的后续任务。
