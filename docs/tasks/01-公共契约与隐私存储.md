# 窗口 A：公共契约、身份权限与隐私存储

## 目标

为 B–G 提供稳定、可编译的模型与接口，并落实本地数据隔离和无损持久化。先读 `00-协同开发总则.md`、`08-公共接口与业务约定.md`。

## 文件归属

独占 `domain/model/`、`domain/port/`、`domain/policy/`、`data/care/`、`security/`、现有 `data/MoodDatabase.kt` 及对应测试；可维护 08 文档。不得修改 Gradle、导航或其他窗口页面。新增依赖交 G。

## 工作清单

1. 第一批先落地公共实体、仓储/适配接口、可注入时钟、明确失败类型和测试替身约定；发布完整签名及“契约已冻结”，让其他窗口开工。
2. 建立演示会话、学生/责任教师范围校验。查询入口和写入入口都校验，不能只过滤 UI。真实身份鉴别保留接口，未配置时拒绝访问，不做万能角色切换后门。
3. 新增量表、授权、预警、干预、AA、任务和审计存储；按 08 分离公开摘要和私有原始数据。
4. 敏感内容采用认证加密，密钥由 Android Keystore 保护，随机 nonce、版本化密文；不得硬编码密钥。文件/备份策略变更提交 G，密钥丢失返回可解释错误，不静默清库。
5. 为现有 Room v3 制定显式增量迁移，保留日记和纪念日。核实旧版本 schema；无法证实 v1/v2 结构时报告，禁止编造迁移或继续以破坏性回退代替迁移。
6. 支持干预启动与 AA 入库的一致性，以及告警/投递幂等存储。数据库不得允许同学生多个活动 AA 档案。
7. 所有列表及详情校验归属，教师仓储只返回白名单摘要和工作信息；不得将完整实体交 UI 后隐藏字段。

## 交付与验收

- Kotlin 契约及本地实现、模型说明、权限矩阵、迁移说明、`handoffs/A.md`。
- 验证本人可读、其他学生拒绝、非责任教师拒绝、责任教师仍不能读取原始数据；覆盖列表和按 ID 查询。
- 验证 v3 升级保留原记录；密文不含明文敏感内容、错误密钥/密文失败可控；验证事务重试不重复 AA 入库。
- 接口冻结和存储完成分别报告。加密原型不等于完成服务端身份安全或校园合规。
