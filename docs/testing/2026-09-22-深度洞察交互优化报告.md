# 深度洞察交互优化报告

## 结论

本轮解决分析页只能阅读、无法继续操作的问题，并恢复“深度洞察”作为分析页的默认第一层。实现保持非诊断边界：CBT 仅用于组织自我反思问题，风险筛查仍以 PHQ-9、GAD-7 为核心，不从日记关键词推断疾病。本轮按要求未执行真机测试。

## 2026-09-23 可发现性修正

双角色导航重构后，深度洞察仍位于学生端“数据洞察”的默认第一页，但学生首页缺少快捷入口，容易被误认为功能已删除。本次在学生首页增加“深度洞察”卡片，并在洞察页首屏补充明确页面标题、本月洞察摘要和下一步建议；原有认知反思、记录规律、情绪趋势、量表评估与日期回看能力均保留。

## 问题与处理

| 编号 | 反馈问题 | 处理结果 |
|---|---|---|
| D01 | 自我反思不能点击 | 改为可点击入口，打开事件、即时想法、支持与反对证据三步反思面板 |
| D02 | 记录心情需要横向滑动回看 | 首页当天记录与分析页本月历史均支持横滑，点击卡片进入对应日期详情 |
| D03 | 缺少个人检测入口 | 深度洞察增加“状态提醒与个人检测”，直接进入 PHQ-9 / GAD-7 自评 |
| D04 | 分析页之前的深度洞察页面消失 | 分析页改为“深度洞察、情绪趋势、量表评估”三个标签，并默认打开深度洞察 |
| D05 | 希望加入 CBT 医学模型 | 实现非诊断性的 CBT 结构化反思，不声称医学模型，不基于自由文本诊断 |
| D06 | 旧心理分析逻辑存在误判风险 | 删除未使用的关键词疾病推断器，避免用词频推断 MDD、PTSD、双相等疾病 |

## 新增扩展

- 计算最近连续记录和最长连续记录，帮助用户了解记录习惯。
- 以每日情绪指数的离散程度显示“较平稳、有波动、波动较明显”，数据不足时不下结论。
- 统计最常记录的时段，只使用记录时间，不分析日记正文。
- 提供当月高点和低点日期入口，可以直接回看当天记录。
- 根据记录天数、波动程度和主导情绪给出下一步建议；需要进一步判断时引导量表自评。

## 交互流程

1. 用户进入“分析”，首先看到深度洞察。
2. 点击“开始自我反思”，系统选择当月情绪指数最低的一天作为可解释的回看起点。
3. 用户可选择回看对应日期的原始记录，或进入编辑器写下此刻想法。
4. 状态提醒只引用记录频次和情绪分值变化；需要进一步筛查时进入 PHQ-9 / GAD-7。
5. 在“情绪趋势”内左右滑动历史心情卡，点击后查看当天完整记录。

## 隐私与判断边界

- 反思引导不读取日记正文，也不提取所谓认知扭曲关键词。
- 情绪曲线、波动等级和变化提醒不是诊断结论。
- PHQ-9、GAD-7 结果仅用于筛查和风险分层，不能替代专业诊断。
- 教师端权限规则不变，只接收整合后的风险标签，不读取学生原始日记或生理数据。

## 剩余边界

本轮没有增加反思答案的独立数据库字段。点击“写下此刻的想法”会进入现有心情记录编辑器，以继续沿用当前的本地数据保护和编辑流程。界面在具体手机上的触控范围、横屏和大字体表现未由本轮真机测试覆盖。
