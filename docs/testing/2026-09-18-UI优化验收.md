# 校园照护界面优化与验收

## 合并记录

上一轮真机修复及功能测试报告（`a2272f3`）已推送，并以快进方式合入远端 `main`、`develop`。本轮设计开发分支为 `codex/care-ui-design`。

## 问题与设计处理

| 页面 | 原有问题 | 本轮调整 |
|---|---|---|
| 照护入口 | 四个同级按钮，主任务不突出，大片留白 | 标题与简短引导、量表主行动卡、图标入口卡、隐私提示；整页可滚动 |
| 量表 | 选项像标签、缺少题号和填写进度、说明堆叠 | 明确题号、进度条、整行单选和高亮边框；说明可展开；保留完整题目、筛查提示及安全提醒 |
| 教师列表 | 空列表仅一行文字；审核列表挤占预警列表高度 | 真实事件数量概览、统一分类、带引导的空状态；审核与预警放入同一个滚动列表 |
| 教师详情 | 原始字段堆叠，处置动作缺少分区 | 学生摘要卡、必要关注标签、跟进处置分区，持续保留隐私说明 |
| AA 随访 | 无档案时只有一句提示；有任务时层级较弱 | 图标空状态、计划概览、基于实际任务的完成进度、日期与任务状态分层 |
| 健康授权 | 紫色默认容器与现有蓝色应用不协调；显示内部授权修订号 | 统一蓝灰容器和卡片形状；改为用户可读授权状态，底层授权版本逻辑保留 |
| 全局颜色 | 默认 Material 容器配色与原应用不统一；部分次要文字偏淡 | 蓝色主色、浅灰蓝分区、20–24dp 间距、24–28dp 卡片圆角；同步定义深色容器，增强浅色主题次要文字对比 |

未改动量表评分、预警阈值、健康授权规则或 AA 退出条件。未增加真实硬件/学校平台接入，不把视觉改版表述为业务缺口已补齐。
